So I made this little script the other day to move my notes from Upnote to Bear. Nothing fancy, but it gets the job done.

It basically takes Upnote's markdown + assets and converts them to textbundles that Bear can import without freaking out. I also threw in some utilities to somewhat mimic Upnote's folder structure using Bear's tag system, which was honestly the trickiest part.

In theory, you could use this for any app that can import TextBundles, not just Bear. The TextBundle format is pretty standard these days among note-taking apps.

If you're stuck in the same boat (Upnote → Bear migration), this might be useful: [github.com/bart6114/upnote2bear](https://github.com/bart6114/upnote2bear/)

By the way, [TextBundles](https://textbundle.org/) are nifty .
